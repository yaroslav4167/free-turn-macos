# FreeTurn macOS v0.2.3 — переход в общий репозиторий

Windows, Linux и macOS теперь выпускаются вместе:
https://github.com/yaroslav4167/free-turn-desktop

Установите это обновление обычным способом. После перезапуска откройте
настройки и проверьте обновления ещё раз: клиент предложит общий v3.0.0,
выбирая только macOS-архив для Apple Silicon или Intel и проверяя SHA-256.

Это минимальное переходное обновление поверх v0.2.2: меняется источник
будущих обновлений. Профили, настройки и установленный utun/launchd-helper
сохраняются. Серверы на VPS не изменяются. Старые релизы и теги остаются доступны.

Приложение подписано ad-hoc, без Apple Developer ID notarization.
