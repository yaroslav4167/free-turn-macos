FreeTurn for macOS 13+ (Apple Silicon / Intel)

1. Unzip the download and drag FreeTurn.app to Applications.
2. Open the application using Finder. Initial builds are ad-hoc signed and are
   not notarized by Apple. macOS may require explicit approval in
   System Settings > Privacy & Security > Open Anyway after an attempted launch.
   Do not disable Gatekeeper globally.
3. Add/import a profile. VPN mode requires a WireGuard/AmneziaWG client config.
4. The first VPN connection requests administrator authorization to install a
   persistent helper. Later connections, including after a reboot, need no new
   password prompt. Only the helper creates utun and changes network routes/DNS;
   the GUI and VPN protocol engine remain unprivileged.
5. FT in the menu bar opens or quits FreeTurn. Closing the window can keep the
   connection active; use Disconnect or Quit to stop it.

Updates: v0.2.0 and later can update from Settings > Download and install.
When upgrading from v0.1.x, replace the entire app manually once. The updater
verifies the release and asks before disconnecting the VPN and restarting.
The entire app and helper are replaced together. Failed startup restores the
previous version. Your account needs write access to /Applications or
~/Applications. Profiles remain in ~/Library/Application Support/FreeTurnDesktop.
The previous app is retained in a private .freeturn-mac-update-* folder beside
FreeTurn.app. Manual installation from Releases remains available.

No Developer ID signature/notarization is included unless the release explicitly
says otherwise. No credentials are needed for downloading releases.

Before uninstalling, disconnect and remove the system helper with:
"/Applications/FreeTurn.app/Contents/MacOS/freeturn-desktop" --remove-vpn-helper
This requests administrator authorization once. Then quit and trash the app.
To repair or explicitly upgrade the system helper, use --configure-vpn-helper.
The helper is root-owned in /Library/PrivilegedHelperTools; app updates retain
this separate copy while the helper protocol remains compatible.

v0.2.2 upgrades the v0.2.1 system helper once, with administrator approval.
This fixes setup timeouts and stale active sessions after a cancelled attempt.
Later connections reuse the installed helper without another password prompt.
